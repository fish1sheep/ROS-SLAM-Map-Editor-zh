# ROS SLAM 地图编辑器
一款基于浏览器的 ROS/ROS2 SLAM 地图在线编辑器

[English Version](README.md)

## 概述
本项目提供了一款基于浏览器的地图编辑器，专为快速便捷地编辑 ROS 和 ROS2 SLAM 地图而设计，例如由流行的 [`slam_toolbox`](https://github.com/SteveMacenski/slam_toolbox) 生成的地图。由于 ROS2 生态系统中一直缺乏此类原生工具，许多机器人开发者和研究人员的工作流中存在显著空白。与其使用命令行或图片编辑器，这是一款免费开源、即开即用的工具，让工程师和研究人员能够直接在浏览器中精细调整 SLAM 地图，还可以使用遮罩叠加层创建禁区。

这款地图编辑器可以理解为一种专用的绘图工具，让用户能够轻松地修改和完善地图。用户可以利用该工具添加、移除或修改地图要素，如墙壁、障碍物等（例如建筑物内家具的变动），以创建更准确、更可靠的环境表示。通过这个工具，用户可以更快完成通常需要用第三方图片编辑器才能实现的工作。

## 功能特性
- [x] 完全基于浏览器的自托管方案（卓越的隐私保护）
- [x] 适配触屏设备和电脑的响应式地图编辑
- [x] 拖放加载 PGM 和 YAML 地图文件
- [x] 拖放加载禁区 PGM 和 YAML 文件（后缀为 `_keepout.pgm` 和 `_keepout.yaml`）
- [x] 支持同时拖放加载两组文件
- [x] 使用 Font Awesome 提供美观的 UI 图标
- [x] 便捷的放大、缩小和自适应按钮
- [x] 反色和自动色阶选项
- [x] 在 PGM 地图中绘制或擦除墙壁
- [x] 在 PGM 地图中绘制或擦除禁区
- [x] 未扫描区域（将区域标记为未知）
- [x] 直线或矩形工具，实现整洁编辑
- [x] 笔刷和线条/矩形绘制时的实时预览叠加层
- [x] 多级撤销和重做功能（支持 `Ctrl+Z` 和 `Ctrl+Y` 快捷键）
- [x] 可选绘制填充矩形
- [x] （按住 `空格键` + 拖拽鼠标）平移地图
- [x] （按住 `Shift` + 滚轮）以光标为中心缩放
- [x] 拖拽动态测量地图上的距离
- [x] 分别下载地图和禁区遮罩（YAML 和 PGM 文件）
- [x] 支持中英文双语切换

## 使用方法
您可以免费使用此工具，访问地址：[https://gyropalm.github.io/ROS-SLAM-Map-Editor/editor.html](https://gyropalm.github.io/ROS-SLAM-Map-Editor/editor.html)

*`maps` 文件夹中包含了示例 SLAM 地图。*

1. 选择您的 `map.yaml` 和 `map.pgm` 文件，将它们拖放到左上角的指定区域。
2. 加载完成后，您可以看到"YAML 预览"和调试信息。您可以使用顶部工具栏的按钮进行缩放，也可以按住 `Shift` 并向上滚动来缩放。
3. 点击"墙壁"按钮开始在目标区域绘制墙壁。使用右侧的滑块调整笔刷大小。（缩放操作不会改变笔刷大小）
4. 您也可以使用"直线"或"矩形"模式来绘制更整洁的墙壁或禁区。要绘制实心填充矩形，请勾选"填充"选项。
5. 选择"擦除"按钮来擦除墙壁。如果希望将某个区域标记为未知，请选择"未扫描"按钮。
6. 要绘制禁区，请点击"禁区"按钮，然后选择"自由绘制"、"直线"或"矩形"模式。
7. 要测量两点之间的距离，请选择"测量距离"模式（双向箭头图标）。然后点击 A 点并拖拽鼠标到 B 点即可查看尺寸，同时显示米和英尺单位。
8. 编辑完成后，点击"下载地图"按钮，系统将提示您分别保存更新后的 `map_edited.yaml` 和 `map_edited.pgm` 文件。同样地，点击"下载禁区遮罩"可保存禁区相关文件。
